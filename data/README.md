# Dataset Information

## Speech Dataset

The speech experiments will use an established research dataset
for cognitive-decline and dementia-related speech analysis.

The original dataset will not be uploaded to this repository
because research datasets may have access and usage restrictions.

## Typing Dataset

The typing experiments will use an appropriate research dataset
containing typing or keystroke information from cognitively
impaired and healthy participants.

The original dataset will not be uploaded to this repository.

## Multimodal Data

Speech and typing data will only be combined for a multimodal
experiment when observations from the same participants are
available and can be appropriately aligned.

## Data Privacy

No private patient data or restricted research datasets will be
stored in this GitHub repository.
